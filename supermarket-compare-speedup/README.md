# supermarket-compare: עדכון מהירות

שאלה נוספת על מוצר באותו יום: כ-4 שניות במקום כ-97 שניות. התוצאות זהות.

## מה השתנה
1. `scripts/geo.py`: אם בדיקת המפה (OpenStreetMap) נכשלה היום, לא מנסים אותה שוב עד מחר.
2. `scripts/price_check.py`: פורטל של רשת שלא ענה (למשל קרפור) לא נבדק שוב במשך 30 דקות, ואחר כך מנסים שוב.

## איך מעדכנים (אחת משתי הדרכים)
- **קובץ zip:** `supermarket-compare.zip` הוא הסקיל המלא אחרי העדכון. מעלים אותו במקום הגרסה הקיימת.
- **patch בריפו של הסקיל:** בתיקיית הריפו `supermarket-compare` מריצים `git apply speedup.patch`, עושים commit ומעלים.
